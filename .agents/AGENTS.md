# Shared .agents directory instructions

This file also supports tools explicitly pointed at `.agents/AGENTS.md`.
Paths in this bundle are repository-root-relative unless a file states otherwise.

Read `.agents/AGENT_RULES.md` and `.agents/skills/SKILLS.md`.
When tools or delegation are involved, read `.agents/CAPABILITIES.md`.
Consult relevant project context in `.agents/ARCHITECTURE.md`.

Do not activate an optional skill merely because you are reviewing or editing its files.
Keep the repository-root `AGENTS.md` loader and optional `CLAUDE.md` imports consistent
with these shared sources. Do not copy vendor-specific workflow rules into the baseline.
